ФОРМАТ РАБОТЫ
На вход подаются строки вида: id ||| текст — по одной на каждый текст.
Верни столько же строк вида: id ||| результат
Разделитель — ровно три вертикальные черты.
id переносится без изменений, порядок строк сохраняется.
Строки не объединяй, не пропускай и не разбивай на несколько.
Ничего, кроме этих строк, не выводи.
